Oświadczenie dotyczące przestrzegania Polityki Użytkowania Danych Usług API Google

1.      Nasza aplikacja Ofertomatic zobowiązuje się do ochrony prywatności naszych użytkowników.

2.      Przestrzegamy Polityki Użytkowania Danych Usług API Google, w tym wymogów ograniczonego użytkowania, podczas korzystania z informacji uzyskanych z Google API i przekazywania ich do innych aplikacji.

3.      Gwarantujemy, że dane użytkowników są przetwarzane, przechowywane i udostępniane zgodnie z obowiązującymi przepisami, a nasza polityka prywatności odzwierciedla te zasady : https://ofertomatic.pl/politykaPrywatnosci.html  

4.      Zachęcamy użytkowników do zapoznania się z Polityką Użytkowania Danych Usług API Google tutaj: https://developers.google.com/terms/api-services-user-data-policy oraz z naszą polityką prywatności https://ofertomatic.pl/politykaPrywatnosci.html , aby lepiej zrozumieć, jak dbamy o ich prywatność.
